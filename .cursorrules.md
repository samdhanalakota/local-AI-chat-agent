# Local AI Chat Agent — Cursor Rules

## What This Project Is
CLI agent connecting to mimOE Studio's local inference API.
TypeScript, Node.js, Axios. No frameworks.

## Files
src/index.ts           — CLI entry point, parses args
src/agent.ts           — orchestrates messages, tools, API calls
src/types/index.ts     — all TypeScript types
src/utils/api.ts       — mimOE HTTP communication
src/utils/parser.ts    — parses TOOL/INPUT from model response
src/utils/tools.ts     — tool definitions and execution
tests/parser.test.ts   — Jest tests for parser
tests/tools.test.ts    — Jest tests for tools

## API
Endpoint: http://192.168.0.111:8083/mimik-ai/openai/v1/chat/completions
Auth: Bearer 1234
Model: smollm-360m
Format: OpenAI-compatible
Stream: false

## Conventions
- Arrow functions
- Async/await not .then
- Types in src/types/ never inline
- Utils are pure functions
- Errors: axios.isAxiosError check, clear messages
- Exit 0 success, exit 1 failure

## Adding a Tool
1. Add to tools array in src/utils/tools.ts
2. System prompt auto-updates
3. Add tests in tests/tools.test.ts
4. Nothing else changes
